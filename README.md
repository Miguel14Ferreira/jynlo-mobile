# Jynlo Mobile

Aplicação Android/iOS da **Jynlo**, desenvolvida com Expo, React Native e TypeScript. Repositório privado em preparação.

**Objetivo:** paridade funcional com a Jynlo Web, usando o mesmo backend e uma experiência própria para telemóvel.

## Estado

- Código da versão 0.7 a integrar.
- A compilação APK é exclusivamente de teste e ainda carece de validação nativa.
- A publicação na Play Store depende de testes reais e da aprovação da conta Google Play Console.

Nenhuma versão deve ser publicada como produção enquanto continuar a utilizar dados de demonstração.
